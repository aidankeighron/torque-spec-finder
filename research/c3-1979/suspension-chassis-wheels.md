# C3 1979 — Suspension, Wheels, Body/Frame

Raw collected data. **Nothing here is ingested yet.** Source tags refer to lineages in
[sources.md](sources.md): **V** = Van Steel catalogue (one source, many mirrors),
**C** = Chilton 1963–83, **G** = GM doc quoted on forum, **B** = restoration book,
**M** = magazine/vendor tech, **F** = uncited forum.

Values are verbatim as printed. `+` = "plus additional torque to align cotter pin hole".
`*` = "at riding height / curb height".

## Generic fastener fallback chart — deliberately NOT transcribed

Chilton p.101 reproduces a full U.S./metric Grade 1-2 / 5 / 6-7 maximum-safe-torque chart,
prefaced verbatim:

> "In the absence of specific torques, the following chart can be used as a guide to the maximum
> safe torque of a particular size/grade of fastener. • There is no torque difference for fine or
> coarse threads. • Torque values are based on clean, dry threads. Reduce the value by 10% if
> threads are oiled prior to assembly. • The torque required for aluminum components or fasteners
> is considerably less."

**Individual cells were not transcribed on purpose** — the OCR column alignment on that page is
unreliable, and mis-transcribing a bolt-grade table is dangerous. Also note this project does
not serve generic chart values as answers.
